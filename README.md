# Verwerkingsopdrachten objectgeoriënteerd programmeren

Welkom bij de Objectgeoriënteerd Programmeren (OOP) verwerkingsopdrachten! 
Deze repository helpt je stap voor stap de belangrijkste concepten van OOP te leren en te oefenen in JavaScript.

## Wat je leert
In deze opdrachten werk je met:
- **Klassen en objecten** – creëer je eigen dieren en verzorgers.
- **Overerving** – hergebruik gedrag van een superclass in subclasses.
- **Inkapseling** – bescherm belangrijke data met private velden en getters/setters.
- **Associatie** – laat objecten samenwerken, zoals een dierentuin met dieren en verzorgers.

## Opbouw van de opdrachten  
Elke opdracht heeft een eigen JavaScript-bestand:
- `opdracht-1.js` – Klassen en objecten
- `opdracht-2.js` – Overerving
- `opdracht-3.js` – Inkapseling
- `opdracht-4.js` – Associatie
Er wordt altijd maar één JavaScript-bestand geladen. Als je met opdracht-2.js bezig bent, doet de code van bijv. opdracht-1.js niet mee.

De `index.html` laadt automatisch de JavaScript van de geselecteerde opdracht. Je kunt wisselen tussen opdrachten via de knoppen bovenaan de pagina.  

## Starten in Codespaces
1. Open de repository in GitHub Codespaces.
2. Wacht tot de container is opgebouwd.
3. Open `index.html` via de server op poort 8080.
4. Bekijk de console in je browser om de output van je code te zien.

## Hoe werken de opdrachten?
- Je schrijft de code in het juiste `opdracht-X.js` bestand.
- Herlaad de pagina in je browser om je wijzigingen te zien.
- Gebruik `console.log()` om extra informatie te printen als dat nodig is.
- Volg de stappen in de comments; elke stap bouwt voort op de vorige.

Laat je creativiteit los op de dieren, verzorgers en de dierentuin, en ontdek hoe objecten samenwerken!
